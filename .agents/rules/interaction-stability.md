# 互動穩定與編輯模式規則（全專案）

本規則適用於整個 Super Dashboard 專案的所有頁面、Mini App、卡片、清單、網格、工具列及原生／Web 混合介面。

## 編輯模式版面穩定
- 進入、離開或切換編輯模式時，所有既有文字、圖示、按鈕、卡片與項目必須維持原本位置、尺寸、順序及佔位。
- 不可編輯的項目不得隱藏、移除或讓其他項目補位；保留原位並以降低明度、灰階或 disabled 狀態呈現。
- 編輯模式只改變必要的可編輯狀態，不得重排不相關 UI。取消編輯應還原狀態，不應重建整頁。

## 最小範圍更新（Minimal Re-render）
- 使用者操作某元件時，只更新該操作直接影響的元件及必要衍生資訊。
- 狀態未改變的元件不得重新 render、重新 mount、替換 DOM、重載圖片或重播動畫。
- 清單選取／取消選取只更新目標項目的 class／狀態與計數，不得重建整份清單。
- 分頁切換只更新必要可見狀態，不得重載仍保留的內容。
- 優先採用局部 DOM 更新、穩定識別碼與差異更新，避免無條件 innerHTML 整批覆寫。

## 動畫與驗證
- 動畫應連續一致，避免閃爍、跳位或重新載入；顯示／隱藏優先使用 opacity／transform。
- 不得攔截既有捲動、點擊或系統邊緣返回手勢。
- 修改後檢查進入編輯、取消、完成、選取、取消選取及分頁切換，確認未操作的圖片、影片、卡片與按鈕沒有被重建。
